Appearance

One theme for the whole extension — the list, this page and the reader. System follows whatever your device is set to.

Export

A full backup holds everything: items, article content, highlights and the schema version. HTML bookmarks are just the address, title and tags — in a format every browser can import.

Import

A Savely backup (.json) or a Pocket export (.csv). Items with the same address are merged, not duplicated — an import never deletes anything and never overwrites content you already have.

Sync across devices

Optional and off by default. Savely has no server — your data travels through a place you pick yourself, and nowhere else.

Automatic backups

Once a day we store item metadata in the database — tags, favorites, archive state, dates. Without article content, so backups stay small. We keep the last three.
